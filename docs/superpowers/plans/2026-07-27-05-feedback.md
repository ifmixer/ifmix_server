# 模块 feedback（反馈）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development 或
> superpowers:executing-plans。步骤用复选框（`- [ ]`）跟踪。

**目标：** 移植旧项目 feedback：结果页提交结构化反馈（预设类别 + 可选备注），后端落库供分析。
纯写入、追加式；不做编辑/删除/限流；`scanRecordId` 只记录不强制校验归属。

**架构：** `FeedbackDocument` 用 `BaseAppDocument`（appId 分片）——**但不软删**（追加式）。`FeedbackService`
组合 `CRUDService`，`submit` 落库返回 id。category 用 Kotlin enum 校验。

**技术栈：** Kotlin 2.3.10、Spring Data MongoDB、Bean Validation。

**环境约束：** 无 Docker → 落库集成测试 Testcontainers（CI）；DTO 校验/service 用 mock 单测。**不要自动 commit。**

- [ ] **步骤 1：`FeedbackCategory`**

```kotlin
package com.ifmix.api.core.modules.feedback

/** 反馈类别（唯一契约来源）。 */
enum class FeedbackCategory {
    LIKED,
    PRICE_TOO_HIGH,
    PRICE_TOO_LOW,
    PRICE_MISSING,
    WRONG_IDENTIFICATION,
    FEATURE_REQUEST,
    MORE_RECOMMENDATIONS,
}
```
> 旧项目对外用小写下划线串（`liked`/`price_too_high`...）。若要严格保持对外契约，DTO 层用
> `@JsonValue`/`@JsonCreator` 或字符串 + 手动校验映射到枚举。**决策点：** 对外用枚举名（大写）还是
> 沿用旧小写串。建议：Jackson 3 默认枚举按 name；如需小写串加 `@JsonProperty` 或自定义。

- [ ] **步骤 2：`FeedbackDocument`（AppScoped 但不软删——追加式）**

```kotlin
package com.ifmix.api.core.modules.feedback

import com.ifmix.api.core.common.db.AppScoped
import com.ifmix.api.core.common.db.BaseDocument
import org.springframework.data.mongodb.core.index.CompoundIndex
import org.springframework.data.mongodb.core.mapping.Document

/** feedback：追加式，appId 分片，不软删。 */
@Document(collection = "feedback")
@CompoundIndex(name = "fb_app_created_idx", def = "{'appId': 1, 'createdAt': 1}")
class FeedbackDocument : BaseDocument(), AppScoped {
    override var appId: String? = null
    var installId: String? = null
    var userId: String? = null
    var scanRecordId: String? = null
    var category: FeedbackCategory? = null
    var note: String? = null
}
```
> 用 `BaseDocument + AppScoped`（非 `BaseAppDocument`）以避免带 `deletedAt`（feedback 追加式无软删）。
> `CRUDRepository` 反射到 `AppScoped` 会注入 appId 过滤，`softDeletable=false` → 删除走物理删（本模块无删除入口）。

## 任务 2：DTO

**文件：** 创建 `modules/feedback/FeedbackDtos.kt`

```kotlin
package com.ifmix.api.core.modules.feedback

import jakarta.validation.constraints.NotNull
import jakarta.validation.constraints.Size

data class SubmitReq(
    @field:NotNull val category: FeedbackCategory? = null,
    @field:Size(max = 1000) val note: String? = null,
    val scanRecordId: String? = null,
)

data class SubmitRes(val id: String?)
```
> `category` 非法值（不在枚举内）由 Jackson 3 反序列化失败 → `HttpMessageNotReadableException` →
> `GlobalExceptionHandler` 返 400（已有处理）。`note` 超长 → `MethodArgumentNotValidException` → 400。

- [ ] **步骤 1：写失败测试**

`submit`：构造 `FeedbackDocument`（installId/userId 来自 ctx、category/note/scanRecordId 来自 req）→
`crud.createOne` 被调 → 返回 id。

- [ ] **步骤 2：实现**

```kotlin
package com.ifmix.api.core.modules.feedback

import com.ifmix.api.core.common.http.RequestContext
import com.ifmix.api.core.common.service.CRUDService

class FeedbackService(private val crud: CRUDService<FeedbackDocument>) {
    fun submit(ctx: RequestContext, req: SubmitReq): String {
        val doc = FeedbackDocument().apply {
            installId = ctx.installId
            userId = ctx.userId
            scanRecordId = req.scanRecordId
            category = req.category
            note = req.note
        }
        return crud.createOne(ctx, doc)
    }
}
```

## 任务 4：装配 + 控制器

**文件：**
- 创建：`modules/feedback/FeedbackConfig.kt`、`bff/customer/CustomerFeedbackController.kt`

- [ ] **步骤 1：`FeedbackConfig`**

```kotlin
package com.ifmix.api.core.modules.feedback

import com.ifmix.api.core.common.db.CRUDRepository
import com.ifmix.api.core.common.db.MongoClusterResolver
import com.ifmix.api.core.common.service.CRUDService
import org.springframework.context.annotation.Bean
import org.springframework.context.annotation.Configuration

@Configuration
class FeedbackConfig {
    @Bean
    fun feedbackRepository(cr: MongoClusterResolver): CRUDRepository<FeedbackDocument> =
        CRUDRepository(cr.primary(), FeedbackDocument::class.java)

    @Bean
    fun feedbackCrudService(feedbackRepository: CRUDRepository<FeedbackDocument>): CRUDService<FeedbackDocument> =
        CRUDService(feedbackRepository)

    @Bean
    fun feedbackService(feedbackCrudService: CRUDService<FeedbackDocument>): FeedbackService =
        FeedbackService(feedbackCrudService)
}
```

- [ ] **步骤 2：控制器**

```kotlin
package com.ifmix.api.core.bff.customer

import com.ifmix.api.core.common.http.RequestContext
import com.ifmix.api.core.modules.feedback.FeedbackService
import com.ifmix.api.core.modules.feedback.SubmitReq
import com.ifmix.api.core.modules.feedback.SubmitRes
import jakarta.validation.Valid
import org.springframework.web.bind.annotation.*

@RestController
@RequestMapping("/customer/core")
class CustomerFeedbackController(private val feedbackService: FeedbackService) {

    @PostMapping("/mutation/feedback/submit")
    fun submit(ctx: RequestContext, @Valid @RequestBody req: SubmitReq): SubmitRes =
        SubmitRes(feedbackService.submit(ctx, req))
}
```
