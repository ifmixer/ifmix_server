# 模块 appconfig（app_info + app_config）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development 或
> superpowers:executing-plans 逐任务实现。步骤用复选框（`- [ ]`）跟踪进度。

**目标：** 移植旧项目 `common/appconfig`：`app_info`（稳定身份注册表，`_id = appId`）+ `app_config`
（追加式版本化配置，apple/google/iap 内嵌），供下游 iap/antique 读取商店凭证与档位映射。

**架构：** `AppInfoDocument : BaseDocument`（无能力接口，`_id` 即客户端 x-app-id）；`AppConfigDocument
: BaseAppDocument(), Versioned`（app 级 + 软删 + 版本化）。读取按"当前版本"（`deletedAt=null`，
partial unique 保证至多一条）+ 60s 内存缓存；写入经 `TxRunner` 追加新版本（软删旧 + 插新 `revision+1`）。
扁平 BO `AppConfig` 摊平内嵌对象，字段名沿用旧项目，下游零改动。

**技术栈：** Kotlin 2.3.10、Spring Data MongoDB、`TxRunner`（副本集事务）、JUnit 5 + Mockito。

**环境约束：** 无 Docker / 本地 Mongo。仓储的版本化/缓存需 Mongo 副本集集成测试（Testcontainers），
本环境跑不了 —— 集成测试**照写**（标 `@Testcontainers`），但只在有 Docker 的 CI 跑；本地用
编译 + 映射/纯函数单元测试验证。**不要自动 commit。**

```kotlin
package com.ifmix.api.core.modules.appconfig

import com.ifmix.api.core.common.db.BaseAppDocument
import com.ifmix.api.core.common.db.Versioned
import org.springframework.data.mongodb.core.index.CompoundIndex
import org.springframework.data.mongodb.core.index.Indexed
import org.springframework.data.mongodb.core.mapping.Document

/**
 * per-app 配置（版本化：追加式，deletedAt 标记历史版本；至多一条当前版本）。
 * 配置内容收进 apple/google/iap 三个内嵌对象；仅查询键/关系键保留为顶层字段。
 * 分片键 appId；partial unique (appId) where deletedAt=null 保证至多一条当前版本。
 */
@Document(collection = "app_config")
@CompoundIndex(
    name = "app_config_appid_current_uq",
    def = "{'appId': 1}",
    unique = true,
    partialFilter = "{ 'deletedAt': null }",
)
class AppConfigDocument : BaseAppDocument(), Versioned {
    var authTenantId: String? = null

    @Indexed
    var appleBundleId: String? = null

    @Indexed
    var androidPackageName: String? = null

    var apple: AppleConfig = AppleConfig()
    var google: GoogleConfig = GoogleConfig()
    var iap: IapConfig = IapConfig()

    override var revision: Int = 1
}

data class AppleConfig(
    val appAppleId: String? = null,
    val issuerId: String? = null,
    val keyId: String? = null,
    val privateKey: String? = null,
    val servicesId: String? = null,
)

data class GoogleConfig(
    val serviceAccount: String? = null,
    val clientIds: GoogleClientIds = GoogleClientIds(),
)

data class GoogleClientIds(
    val ios: String? = null,
    val android: String? = null,
    val web: String? = null,
)

data class IapConfig(
    val productTierMap: Map<String, String> = emptyMap(),
    val env: String? = null,
)
```

@Test
fun `flattens embedded config and defaults iapEnv to production`() {
    val doc = AppConfigDocument().apply {
        appId = "app1"
        revision = 3
        appleBundleId = "com.x.app"
        apple = AppleConfig(issuerId = "iss", keyId = "kid")
        iap = IapConfig(productTierMap = mapOf("p1" to "pro"), env = null)
    }
    val flat = AppConfigMapper.toFlat(doc)
    assertThat(flat.revision).isEqualTo(3)
    assertThat(flat.appleIssuerId).isEqualTo("iss")
    assertThat(flat.appleBundleId).isEqualTo("com.x.app")
    assertThat(flat.iapEnv).isEqualTo("production")
    assertThat(flat.productTierMap).containsEntry("p1", "pro")

## 索引与分片说明

- `app_config`：partial unique `(appId) where deletedAt=null`（`@CompoundIndex` 已声明）；
  `appleBundleId`、`androidPackageName` 单字段索引（webhook 反查）。分片键 `appId`（唯一索引以分片键为前缀 ✓）。
- `app_info`：`slug` 唯一稀疏索引；`_id = appId`，不分片。
- `application.yml` 已开 `spring.data.mongodb.auto-index-creation: true`，注解索引启动时建。
  分片本身（`shardCollection`）为部署引导脚本职责，超出本模块代码范围。
