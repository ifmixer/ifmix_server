# 模块 AI（Spring AI 扫描 + Agnes 多 key 池）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development 或
> superpowers:executing-plans。步骤用复选框（`- [ ]`）跟踪。

**目标：** 实现 antique 的真实 AI 扫描，替换 `2026-07-27-02-antique.md` 的 `StubScanRunner`：多模态
图片 → 结构化 `ScanResult`（~40 字段，唯一契约）。LLM 调用走 **Spring AI `ChatClient`**（结构化输出
绑定 + 多模态），key 选择走移植自旧项目的 **Agnes 多 key 池**（Redis 配额记账 + 加权随机 + 429 冷却 +
超时归还 + 跨 key/跨模型 fallback）。

**为何保留多 key 池（方案 B 理由）：** 不是为了省钱，而是**单 key 有频率限制**——多 key 轮换 + 配额
记账 + 429 冷却，避免单 key 撞到 provider 频率限制时用户扫描请求直接失败。这是可用性诉求，删不得。

**架构（方案 B）：** `AgnesKeyStore`（Redis + DB 缓存）负责挑 key/记账/冷却；`AgnesChatClientFactory`
用挑中的 key 现建 Spring AI `ChatClient`（`OpenAiApi` mutate baseUrl+key）；`SpringAiScanRunner`
（实现 antique 的 `ScanRunner` 接口）编排：构造多模态消息 → 主/备模型循环 → 每模型经 keystore 轮换
调用 → 结构化输出绑定 `ScanResult` → 首个成功即返回，全失败抛 `AI_UNAVAILABLE`。
> **退化成方案 A（纯 Spring AI 单 key）：** 删除 `AgnesKeyStore`/`AgnesKeyDocument`/工厂的 key 循环，
> 用一个固定 `ChatClient` bean（env 单 key）直接调用。`SpringAiScanRunner` 的 fallback/parse 逻辑不变。

**技术栈：** Kotlin 2.3.10、Spring Boot 4.1、**Spring AI 1.0.x**（`spring-ai-starter-model-openai`）、
Spring Data Redis（Lettuce）、Spring Data MongoDB、虚拟线程。

**环境约束：** 无 Docker + 无真实 Agnes key → 端到端调用联调推迟；keystore 加权挑选/配额/冷却用
**mock Redis + 注入 rng** 单元测试，runner 的模型 fallback/解析用 **mock ChatClient** 单元测试。
**不要自动 commit。**

## 任务 4：AgnesKeyStore（Redis 配额/冷却/加权挑选）

**文件：** 创建 `common/ai/AgnesKeyStore.kt`

- 预扣越限（INCR 返回 > rateLimit）→ DECR + 短冷却 + 重挑。
- `release` → DECR usageKey；`markUnavailable` → 设 cooldown，TTL 到窗口结束。

```kotlin
package com.ifmix.api.core.common.ai

import org.springframework.data.redis.core.StringRedisTemplate
import java.time.Duration

data class PickedKey(val id: String, val key: String, val usageKey: String)

/** Agnes 多 key 池：Redis 配额记账 + 冷却 + 按剩余额度加权随机挑选。DB key 列表带 TTL 缓存。 */
class AgnesKeyStore(
    private val redis: StringRedisTemplate,
    private val loadKeys: () -> List<AgnesKeyDocument>,
    private val cacheTtlMs: Long = 30_000,
    private val now: () -> Long = { System.currentTimeMillis() },
    private val rng: () -> Double = { Math.random() },
) {
    @Volatile private var cache: Pair<Long, List<AgnesKeyDocument>>? = null

    private fun keys(): List<AgnesKeyDocument> {
        cache?.let { (at, ks) -> if (now() - at < cacheTtlMs) return ks }
        val ks = loadKeys()
        cache = now() to ks
        return ks
    }

    private fun windowStart(windowSec: Int): Long = (now() / 1000 / windowSec) * windowSec
    private fun usageKey(k: AgnesKeyDocument): String = "agnes:use:${k.id}:${windowStart(k.windowSec)}"
    private fun cooldownKey(id: String): String = "agnes:cool:$id"
    private fun applicable(k: AgnesKeyDocument, model: String): Boolean =
        k.models.contains("*") || k.models.contains(model)

    /** 挑一个可用 key（含预扣）。无候选返回 null（上层判 AI_UNAVAILABLE）。 */
    fun pickKey(model: String): PickedKey? {
        val base = keys().filter { applicable(it, model) }
        if (base.isEmpty()) return null
        repeat(base.size) {
            val avail = base.mapNotNull { k ->
                val id = k.id ?: return@mapNotNull null
                if (redis.hasKey(cooldownKey(id))) return@mapNotNull null
                val used = redis.opsForValue().get(usageKey(k))?.toIntOrNull() ?: 0
                val remaining = k.rateLimit - used
                if (remaining > 0) k to remaining else null
            }
            if (avail.isEmpty()) return null
            val chosen = weightedPick(avail)
            val uk = usageKey(chosen)
            val newUsed = redis.opsForValue().increment(uk) ?: 1L
            if (newUsed == 1L) redis.expire(uk, Duration.ofSeconds(chosen.windowSec.toLong()))
            if (newUsed > chosen.rateLimit) {
                redis.opsForValue().decrement(uk)
                redis.opsForValue().set(cooldownKey(chosen.id!!), "1", Duration.ofSeconds(5))
                return@repeat
            }
            return PickedKey(chosen.id!!, chosen.key!!, uk)
        }
        return null
    }

    /** 429：冷却该 key 到窗口结束。 */
    fun markUnavailable(id: String) {
        val k = keys().firstOrNull { it.id == id }
        val windowSec = k?.windowSec ?: 300
        val ttl = (windowSec - (now() / 1000 % windowSec)).coerceAtLeast(1)
        redis.opsForValue().set(cooldownKey(id), "1", Duration.ofSeconds(ttl))
    }

    /** 超时/未消耗配额：归还预扣。 */
    fun release(picked: PickedKey) {
        redis.opsForValue().decrement(picked.usageKey)
    }

    private fun weightedPick(items: List<Pair<AgnesKeyDocument, Int>>): AgnesKeyDocument {
        val total = items.sumOf { it.second }
        var r = rng() * total
        for ((k, remaining) in items) {
            r -= remaining
            if (r < 0) return k
        }
        return items.last().first
    }
}
```

```kotlin
import org.springframework.ai.chat.client.ChatClient
import org.springframework.ai.openai.OpenAiChatModel
import org.springframework.ai.openai.OpenAiChatOptions
import org.springframework.ai.openai.api.OpenAiApi
import org.springframework.beans.factory.annotation.Value
import org.springframework.stereotype.Component

/**
 * 用挑中的 Agnes key 现建 Spring AI ChatClient（OpenAI 兼容）。ChatClient/OpenAiApi 为轻量对象，
 * 每请求按 key + model 构建可接受。真实的重试/轮换在 keystore + runner 层，不用 Spring AI retry。
 */
@Component
class AgnesChatClientFactory(
    @param:Value("\${app.agnes.base-url}") private val baseUrl: String,
) {
    fun forKey(apiKey: String, model: String): ChatClient {
        val api = OpenAiApi.builder().baseUrl(baseUrl).apiKey(apiKey).build()
        val model0 = OpenAiChatModel.builder()
            .openAiApi(api)
            .defaultOptions(OpenAiChatOptions.builder().model(model).build())
            .build()
        return ChatClient.create(model0)
    }
}
```

```kotlin
package com.ifmix.api.core.common.ai

import com.ifmix.api.core.common.http.ApiError
import com.ifmix.api.core.common.http.ErrorCode
import com.ifmix.api.core.common.http.RequestContext
import com.ifmix.api.core.modules.antique.ScanInput
import com.ifmix.api.core.modules.antique.ScanOutput
import com.ifmix.api.core.modules.antique.ScanResult
import com.ifmix.api.core.modules.antique.ScanRunner
import org.springframework.ai.chat.messages.SystemMessage
import org.springframework.ai.chat.messages.UserMessage
import org.springframework.ai.content.Media
import org.springframework.util.MimeTypeUtils
import java.net.URI

/**
 * 真实扫描：主/备模型循环，每模型经 keystore 轮换挑 key，用 Spring AI ChatClient 调多模态 +
 * 结构化输出绑定 ScanResult。首个成功返回；429 冷却轮换、超时归还预扣、耗尽抛 AI_UNAVAILABLE。
 */
class SpringAiScanRunner(
    private val keyStore: AgnesKeyStore,
    private val clientFactory: AgnesChatClientFactory,
    private val defaultModel: String,
    private val fallbackModel: String?,
    private val maxRetries: Int,
) : ScanRunner {

    override fun run(ctx: RequestContext, input: ScanInput): ScanOutput {
        val models = listOfNotNull(defaultModel, fallbackModel?.takeIf { it.isNotBlank() })
        for (model in models) {
            val result = tryModel(ctx, input, model)
            if (result != null) return ScanOutput(result, model)
        }
        throw ApiError(ErrorCode.AI_UNAVAILABLE, "ai unavailable")
    }

    /** 单模型：keystore 轮换重试，成功解析返回 ScanResult，否则 null（换下一模型）。 */
    private fun tryModel(ctx: RequestContext, input: ScanInput, model: String): ScanResult? {
        repeat(maxRetries) {
            val picked = keyStore.pickKey(model) ?: return null
            try {
                val client = clientFactory.forKey(picked.key, model)
                val system = SystemMessage(ScanPrompt.systemText(input.language ?: "en", input.currency ?: "USD"))
                val user = UserMessage.builder()
                    .text(ScanPrompt.USER_TEXT)
                    .media(Media(MimeTypeUtils.IMAGE_JPEG, URI.create(input.imageUrl)))
                    .build()
                return client.prompt()
                    .messages(system, user)
                    .call()
                    .entity(ScanResult::class.java)
            } catch (e: Exception) {
                when {
                    isRateLimited(e) -> keyStore.markUnavailable(picked.id)   // 429：冷却轮换
                    isTimeout(e) -> keyStore.release(picked)                  // 超时：归还预扣
                    // 5xx/解析失败：保留预扣，轮换
                }
                // 继续 repeat 换 key
            }
        }
        return null
    }

    private fun isRateLimited(e: Exception): Boolean =
        e.message?.contains("429") == true || e.javaClass.simpleName.contains("RateLimit", ignoreCase = true)

    private fun isTimeout(e: Exception): Boolean =
        e.message?.contains("timeout", ignoreCase = true) == true ||
            e.javaClass.simpleName.contains("Timeout", ignoreCase = true)
}
```
> **说明：** Spring AI `.call().entity(ScanResult::class.java)` 用 `BeanOutputConverter`（Jackson 绑定，
> snake_case 由 `@JsonNaming` 生效）。多模态 `Media(IMAGE_JPEG, URI)` 让 provider 按 URL 取图（与旧
> `image_url` 一致）。429/超时的异常类型随 Spring AI/底层 client 而定——`isRateLimited`/`isTimeout` 先
> 用消息/类名启发式，**联调期按真实异常类型收紧**（这是明确的联调待办，非占位逻辑缺失）。
> Media/UserMessage.builder API 以 Spring AI 1.0 实际为准。
